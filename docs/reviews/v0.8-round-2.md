## 问题与关闭证据

### P1：未知副作用仍触发下一模型回合——已关闭

原 `AgentLoop` 将最终变更回执写入失败返回的 `status=unknown` 当作一般可修复工具失败。独立复现先执行 write `A`，注入 `ChangeStore.complete` 保存错误，再让第二个模拟模型回合发出新 ID 的 append `B`：出现两次模型回合，实际文件为 `AB`。这突破了“未知执行须先核对”的边界。

主会话修复后，本代理重新运行原失败项：文本工具只执行一轮，文件为 `A`；原生工具首项 unknown 后第二项 skipped、第二文件不存在，不进入下一模型回合，错误提示要求核对。停止原因保持 `unconfirmed_side_effect`。

回归：`tests/test_v08_round2_core.py` 的文本/原生 unknown 两项。

### P1：UI 文件恢复的未知回执未暂停运行——已关闭

另一代理先复现：UI revert 已实际恢复文件，最后 `ChangeStore.complete` 保存失败；service 仍无 recovery，下一输入直接执行。

修复将 UI revert 纳入 service 执行日志：先提交意图，成功保存后才提交完成标记；新增未知意图或无法核实记录时暂停队列，重启仍需明确确认。操作前后的 ChangeStore 没有新增意图时，已知版本冲突写入明确失败完成标记，保留外部内容且不虚构 recovery。输入锁和恢复预约覆盖整个线程 I/O，恢复期间禁止并发运行/导航。

新增服务测试覆盖：最终回执错误后文件已恢复、后续发送被阻止、重启仍要求核对、确认后不反复出现；已知冲突不进入 recovery；恢复期间排队/legacy run 竞争。另一代理按原未知回执失败条件独立复核通过。

### P2：类型化停止原因被一般 error 覆盖——已关闭

原生 unknown 的副作用停止已经有效，但 run 的出口曾将 `unconfirmed_side_effect` 改成 `error`。独立原生测试指出该字段差异。主会话修复后，两条路径均保留类型化原因。

### P2：开放策略与桌面写入范围表达不一致——已明确边界

独立实测：裸 CLI Executor 的 open 策略可以写工作区外；桌面注入 ChangeStore 后，外部文件写入在变更意图前拒绝，但 open 读取外部文件仍允许。原因是 ChangeStore 的变更/恢复路径固定为当前工作区，区别不是模型版本或文件新鲜度错误。

本轮保留执行行为。已亲读最终设置文案：“开放 · 放宽命令与敏感读取”“开放策略可读取工作区外内容；带变更记录的文件写入仍限当前工作区。”不再宣称开放文件写入已有全路径支持。该项不构成已复现的越界写漏洞。

## 剩余边界

### 收尾追加：shell 输出先全读再截断 P1——源码已修，须随最终包复验

实复现 stdout/stderr 各 1 MiB 时，原 `Process.communicate` 返回各 1,048,576 字节，随后 Executor 才截成各 80,000 字符，说明输出上限仅限制展示而未限制捕获内存。

经主会话授权，本代理仅修改 `_bash` 与有界读取 helper，沿用外部进程接口的并发排空/取消清理方式，没有跨模块引入循环依赖。stdout/stderr 并行以 64 KiB 读取，增量 UTF-8 解码，按字符限额保留；默认各8万字符、单流硬上限100万，非正旧配置回退8万。超时/取消保持读取任务运行，先终止 owned process tree，再等待全部读取与 wait 任务结束。

`python -B -m unittest discover -s tests -p 'test_bounded_bash.py' -v`：8 项通过。真实子进程每流2 MiB、合计4 MiB输出，禁止调用 `communicate`，最终各8万字符、Python追踪峰值小于2 MiB；UTF-8跨块与残缺尾字节、非正/超大配置、真实超时与取消均通过，子进程已退出。旧 cancellation fixture 只适配到 drain/wait 接缝，原“取消抛异常、仅清理一次 owned process”的断言保留且单项通过。

主会话另指出父shell已退出但后台子进程继承管道的清理挂起分支。本代理新增真实父/子进程 fixture、0.3秒命令超时与外层3秒上限，实测有界返回并提示管道未关闭，结果标记 `unknown`，触发已有当前run停止与service恢复确认，不自动修复/盲重试。实现最多再等待1秒，之后关闭本机管道、取消并等待读取任务；测试finally仅清理自己记录的子进程PID。该分支保障时间限额退出，不宣称已使用Windows Job Object完整隔离后台派生进程。
