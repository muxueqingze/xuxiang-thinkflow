## 减少重复输入

精确 read 投影覆盖 tf 自动反馈、tf 显式反馈及两种原生格式。只引用当前请求仍存在的同版本、同范围正文；源正文被压缩移走时重新提供原文。保存的历史不被引用占位替换，文件版本、范围说明、错误和工具配对保持。

固定轨迹的第 3 次请求，messages 以 `ensure_ascii=False` 紧凑 JSON 计字符，系统提示不在该测量内：

| 反馈方式 | 投影前 | 投影后 | 减少 | 请求总数 |
|---|---:|---:|---:|---:|
| tf 自动反馈 | 12,375 | 6,665 | 5,710 | 3 → 3 |
| tf need_result | 12,361 | 6,651 | 5,710 | 3 → 3 |

其中重复正文由 5,600 字符改为 90 字符引用。同批两次独立读取仍以 2 次请求完成。这里计量的是固定请求字符；历史 Pi 三题的 61.11% token 结果保持原记录。
