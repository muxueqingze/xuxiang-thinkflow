# 代码地图

按任务只读对应模块。原理见[核心论文](predictable-tool-calls.md)，整体结构见[DESIGN](../DESIGN.md)，当前效率工作见[接力](efficiency-handoff.md)，下一阶段选型见[成熟harness参照](harness-direction-20261110.md)。

| 要改什么 | 入口与职责 |
|---|---|
| 流中执行、信息边界、原生调用 | `src/agent_loop.py`：provider 流 → parser → FIFO/原生执行 → observation；CLI 和桌面共用 |
| 命令语法、可见文本过滤 | `src/parser.py`、`src/text_filter.py`；完整命令解析与用户界面过滤分开 |
| 工具正文与回执 | `src/context.py` 保存本地账本并生成首次整批反馈；`src/feedback.py` 合并observation并投影重复read |
| 长程要求与上下文压缩 | `src/conversation.py` 保存真实用户原文、request引用与摘要条目；`src/compaction.py` 保留当前输入并投影摘要；AgentLoop提供文本/原生recall，状态随snapshot保存。见[本轮依据](long-context-20261110.md) |
| 文件、shell 与 Python 代码块 | `src/executor.py`，shell/python共用`_run_process`；`src/changes.py` 负责文件版本与变更记录；`src/security.py` 沿用现有授权策略 |
| 工具描述、按需开放与扩展 | `src/tool_registry.py`、`src/interfaces.py`、`src/skills.py`；`AgentLoop._load_tools`开放同一registry内schema；内置说明在 `src/skills/thinkflow/SKILL.md` |
| 模型适配、设置和请求参数 | `src/provider.py`、`src/model_registry.py`；实际运行请求由 `AgentLoop` 组装 |
| 协议与可选工程提示 | `src/prompts.py`保存两层正文；`AgentLoop.build_system_prompt`注入实际协议；`src/cli.py`解析用户/推荐指引与配置；`src/runtime_context.py` 加载工作区约定；`src/session.py` 保存快照 |
| 桌面服务与界面 | `src/desktop_service.py`、`desktop/`；桌面说明见 [desktop.md](desktop.md) |
| 原始用量与工程对照 | `bench/efficiency_20261011/` 复用 `bench/harness_benchmark_20260929/tasks.py` 的任务与独立判题；旧实验目录只读保留 |
| 长上下文质量复现 | `bench/long_context_20261110/run.py` 为显式启用的付费恢复探针；`tests/test_conversation_context.py` 为离线回归 |

效率改动围绕“输入是否提供新信息”处理消息。先看当前接力与对应代码，不自动加载所有历史 benchmark、审查或测试资料。
