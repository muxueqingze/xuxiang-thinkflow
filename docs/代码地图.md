# 代码地图

按任务只读对应模块。原理见[核心论文](predictable-tool-calls.md)，整体结构见[DESIGN](../DESIGN.md)，当前效率工作见[接力](efficiency-handoff.md)，下一阶段选型见[成熟harness参照](harness-direction-20261110.md)。

| 要改什么 | 入口与职责 |
|---|---|
| 流中执行、信息边界、原生调用 | `src/agent_loop.py`：provider 流 → parser → FIFO/原生执行 → observation；CLI 和桌面共用 |
| 命令语法、可见文本过滤 | `src/parser.py`、`src/text_filter.py`；完整命令解析与用户界面过滤分开 |
| 工具正文与回执 | `src/context.py` 保存内容/进程通道及精确read位置；`src/feedback.py` 合并observation并统一文本/两种原生read投影；`src/message_projection.py` 转换发送协议，保持原始历史 |
| 完整工具输出与回取 | `src/output_capture.py` 流式保存及尾部预览；`src/output_store.py` 不可变原文；`src/recall.py` 共用字符范围与字面搜索；回执映射在`src/context.py`，持久根由`src/session.py`绑定 |
| 长程要求与上下文压缩 | `src/conversation.py` 保存用户原文、冻结输入、request引用及当前run的补充；`src/compaction.py` 原文保留同一任务的全部活跃输入；`src/task_plan.py`可选context存阶段决定/文件导航，沿现有请求和快照投影。见[阶段设计](research/context-design-20261113.md) |
| 文件、shell 与 Python 代码块 | `src/executor.py`结算实际文件结果；shell/python/custom/image-command共用进程及输出捕获；`src/process_owner.py`统一Windows Job/POSIX进程组；`src/changes.py`管理版本与变更记录 |
| 按行读取与精确编辑基线 | `src/file_observations.py` 分块读取、计算SHA256及维护字符覆盖；`src/executor.py` 检查版本与唯一old_text，区分局部edit和全文操作；正式回归`tests/test_read_ranges.py`，见[范围读取记录](read-ranges-20261111.md) |
| 工作区搜索 | `src/workspace_search.py` 按项目内的 `.gitignore` 惰性遍历；`src/executor.py` 的 grep 保留 Python 正则、路径权限及命中行，三个搜索工具共用取消与结果上限；见[搜索验证](reviews/search-20261113.md) |
| 工具描述、按需开放与扩展 | `src/tool_registry.py`是direct/tf/native的实际分发源，保留结构化结果；`src/interfaces.py`复用Executor；`AgentLoop._load_tools`读取实时registry；内置说明在`src/skills/thinkflow/SKILL.md` |
| 模型适配、设置和请求参数 | `src/provider.py`、`src/model_registry.py`；实际运行请求由 `AgentLoop` 组装 |
| 配置分层、按项设置与嵌入 | `src/configuration.py`解析层级与来源；`src/config_cli.py`提供无模型配置命令；`src/runtime.py`装配真实配置及Agent；[配置与SDK](configuration.md) |
| 实际输入与近期内容预算 | `src/context_budget.py`估算最终输入；`AgentLoop`在待反馈注入后触发本地整理，`src/compaction.py`保留连续近期内容及完整批次；回归`tests/test_context_budget.py` |
| 协议与可选工程提示 | `src/prompts.py`保存两层正文；`AgentLoop.build_system_prompt`注入实际协议；`src/runtime.py`解析用户/推荐指引；`src/runtime_context.py`加载工作区约定；`src/session.py`保存快照 |
| CLI 输入与任务收尾 | `src/interactive_controller.py`统一原文队列、/btw与/steer、停止及退出等待；`AgentLoop.steering_source`在完整批次边界取补充；`src/cli.py`和`src/tui.py`只处理视图；桌面同一路径由持久输入队列供给 |
| CLI/SDK 持久回执 | `SessionStore.bind`在`src/events.py`注册独立同步观察者；`src/session.py`保存意图/回执、检查点、增量与会话索引；`src/session_delta.py`只负责变化编码/恢复；`create_agent(..., session_store=...)`接入宿主 |
| Anthropic 原始内容块 | `AgentLoop._process_stream`按SSE块边界保存thinking/signature/redacted/text/tool_use，`_handle_traditional_tools`连接工具执行与回传；仅完整块进入历史 |
| 生产请求与用量 | `src/usage_tracker.py`区分HTTP尝试/逻辑轮/完整或部分usage/活动时间；AgentLoop及baseline按发送和SSE事件记账；桌面与CLI读取相同事实 |
| 思考选项和实发请求 | `src/provider.py`统一种类/档位/标签和三种协议参数；CLI及Desktop均使用同一契约 |
| 桌面视觉与布局 | **唯一视觉入口 `desktop/renderer/styles.css`**；`workbench-layout.js`负责面板尺寸/动效，`composer-controls.js`负责模型/权限/思考/上下文轻菜单，`settings-panel.js`与`developer-settings.js`负责配置交互 |
| 桌面终端、Git与目录 | `src/desktop_terminal.py`管理工作区 ConPTY；`src/workspace_git.py`只读状态与差异；`src/desktop_catalog.py`投影实际工具与技能；前端对应`terminal-panel.js`和`git-panel.js` |
| 文件标签与阅读状态 | `desktop/renderer/workspace-panel.js`管理多文件预览、版本与滚动位置；工作区切换清理，同工作区会话切换保留；Git行内展开由`git-panel.js`管理 |
| 桌面服务与界面 | `src/desktop_service.py`、`desktop/`；桌面说明见 [desktop.md](desktop.md) |
| Windows 桌面打包 | `scripts/build-desktop.cjs` 打包 Electron 与 Python 服务；`scripts/desktop/python-runtime.cjs` 准备官方独立 Python 工具运行时，`python_stdin.py` 处理其工作区导入与 stdin；从同一应用目录生成便携 ZIP 和安装程序；`desktop/installer.iss` 定义安装与卸载 |
| 原始用量与工程对照 | `bench/efficiency_20261011/` 复用 `bench/harness_benchmark_20260929/tasks.py` 的任务与独立判题；旧实验目录只读保留 |
| 长上下文质量复现 | `bench/long_context_20261110/run.py` 为显式启用的付费恢复探针；`tests/test_conversation_context.py` 为离线回归 |

效率改动围绕“输入是否提供新信息”处理消息。先看当前接力与对应代码，不自动加载所有历史 benchmark、审查或测试资料。
