## 第二轮细看：输入区的四个小控件

ThinkFlow 现有的模型和权限按钮都跳到设置。审批卡把请求输入直接序列化成 JSON。上下文页脚把当前保留条数、字符数、历史显示窗口和导出说明拼在同一行。累计用量另在执行栏。可从输入区就地完成的操作有三类，选择下一次配置、核对当前授权、查看上下文。参见 [输入区](../../desktop/renderer/index.html#L38-L48)、[状态渲染](../../desktop/renderer/app.js#L130-L166)、[权限和设置动作](../../desktop/renderer/app.js#L301-L342)。

### 权限模式

ZCode 左侧触发器高 28px，顺序是盾牌图标、当前模式、下箭头。窄区只显示盾牌，保留可访问名称。菜单在上方间隔 4px，宽 256px。首行是独立的「计划模式」复选，分隔后是「变更前确认 / 自主模式 / 完全访问」三项单选。每项图标对齐两行文案，右端显示选择标记。勾选计划后，按钮旁用小竖线与可关闭的灯泡标记表示它。菜单使用共享 Radix Dropdown，100ms 淡入淡出和 95% 缩放，向上菜单从触发器方向滑入。Ctrl+Shift+M 循环权限；菜单关闭后桌面回输入框，触摸和等待完全访问确认时不抢焦点。进入完全访问才请求一次确认，切换普通模式直接更新草稿配置。[模式接入输入区](https://github.com/zai-org/ZCode/blob/b95ebaffeab641907b38652f45c1502bd762972d/packages/ui/src/v4/ConversationComposer.tsx#L2800-L2820)、[模式菜单与焦点](https://github.com/zai-org/ZCode/blob/b95ebaffeab641907b38652f45c1502bd762972d/packages/ui/src/v4/composer/V4ComposerModeControls.tsx#L65-L229)、[菜单动效](https://github.com/zai-org/ZCode/blob/b95ebaffeab641907b38652f45c1502bd762972d/packages/ui/src/components/ui/dropdown-menu.tsx#L24-L50)、[快捷键](https://github.com/zai-org/ZCode/blob/b95ebaffeab641907b38652f45c1502bd762972d/packages/ui/src/v4/composer/toolbarShortcuts.ts#L1-L10)、[完全访问确认](https://github.com/zai-org/ZCode/blob/b95ebaffeab641907b38652f45c1502bd762972d/packages/ui/src/hooks/useConfirmDialog.ts#L23-L45)、[下一次提交读取模式](https://github.com/zai-org/ZCode/blob/b95ebaffeab641907b38652f45c1502bd762972d/packages/ui/src/v4/SessionPane.tsx#L5210-L5216)。

ThinkFlow 可把现有「平衡权限 / 只读 / 桌面开放」做成同一浮层三行，第一行显示模式，第二行写具体会发生什么。已有模式语义不同于 ZCode 的三档，名称和策略保持本项目契约。Esc、点击外部关闭，方向键移动、Enter 选择，关闭恢复输入焦点。平衡和只读一击生效，桌面开放确认一次；只读仅说明文件和命令的限制。配置需要改动运行内核时沿用当前空闲门槛，待有按请求固化配置的能力再允许运行中为下一条选择。

### 单次授权

ZCode 从 SessionPane 的底部将真实 pending interaction 投给权限卡。普通权限卡的中间工具壳常开，命令以等宽原文展示，描述只解释目的。命令先占至多 3 个可视行，ResizeObserver 检测真实溢出后才显示「展开命令」，点开至多 10 行并可纵滚，复原时滚回开头。预览不显示运行中动画或输出。选项由请求提供，排序允许一次、持久允许、完全访问、拒绝一次、持久拒绝；默认首项，Tab 或方向选择，Enter 确认，数字 1–3 可直达选项。请求按 ID 锁应答，失败原位反馈。等待期间保留编辑器挂载和草稿，卡片暂用输入区；软审核不占输入区。[阻塞判定](https://github.com/zai-org/ZCode/blob/b95ebaffeab641907b38652f45c1502bd762972d/packages/ui/src/v4/SessionPane.tsx#L1778-L1790)、[权限卡挂在底部](https://github.com/zai-org/ZCode/blob/b95ebaffeab641907b38652f45c1502bd762972d/packages/ui/src/v4/SessionPane.tsx#L6513-L6552)、[编辑器保留](https://github.com/zai-org/ZCode/blob/b95ebaffeab641907b38652f45c1502bd762972d/packages/ui/src/v4/ConversationComposer.tsx#L2881-L2903)、[工具预览状态](https://github.com/zai-org/ZCode/blob/b95ebaffeab641907b38652f45c1502bd762972d/packages/ui/src/PermissionDialog.tsx#L345-L429)、[命令展开](https://github.com/zai-org/ZCode/blob/b95ebaffeab641907b38652f45c1502bd762972d/packages/ui/src/ToolCallBlocks/renderers/ExecuteCommand.tsx#L7-L69)、[选项排序](https://github.com/zai-org/ZCode/blob/b95ebaffeab641907b38652f45c1502bd762972d/packages/ui/src/lib/permissionRequest.ts#L71-L105)、[键盘与确认](https://github.com/zai-org/ZCode/blob/b95ebaffeab641907b38652f45c1502bd762972d/packages/ui/src/PermissionDialog.tsx#L765-L849)、[响应状态](https://github.com/zai-org/ZCode/blob/b95ebaffeab641907b38652f45c1502bd762972d/packages/ui/src/v4/V4InteractionDialogs.tsx#L360-L418)。

ThinkFlow 的 RPC 只提供 UUID、工具和输入，以及一次性布尔应答。卡片可用「允许执行命令？」和任务真实参数直接说明操作。命令为主体，目录或路径只在有数据时显示，原始参数放进明确标为「更多参数」的折叠项。按钮用主按钮「允许一次」和次级「拒绝」，没有持久授权选项的后端契约。等待发回执时只禁两项应答按钮，错误留在卡片并允许再次选择。可继续看到已受理的队列。上下文里的普通工具行记录「待授权」，全局不再叠一份等待横幅和正在执行动画。

### 当前上下文

ZCode 用 composer 右侧的 14px 环形图标，环从 12 点起画 used/max；桌面 hover 或 focus 即显示，触摸按下打开。上方浮层宽 320px、偏移 2px。首行「上下文容量」右对齐 `24k/128k (19%)`，下一行 8px 占用条。有分项时按消息、系统提示、技能和工具定义等列占比。细分占比按字符来源计算，顶部总量来自运行时 `usage.contextWindow` 的 usedTokens/maxTokens。无有效占用数据且无套餐时不渲染；缓存命中率按有意义的数据出现。该提交向控件传了压缩回调，浮层 JSX 实际没有压缩按钮。实际手动压缩命令进入 SessionPane 的 slash 解析。[取运行时窗口值](https://github.com/zai-org/ZCode/blob/b95ebaffeab641907b38652f45c1502bd762972d/packages/ui/src/v4/composer/V4ComposerToolbar.tsx#L1149-L1158)、[输入区挂载](https://github.com/zai-org/ZCode/blob/b95ebaffeab641907b38652f45c1502bd762972d/packages/ui/src/v4/composer/V4ComposerToolbar.tsx#L1290-L1301)、[环和 hover](https://github.com/zai-org/ZCode/blob/b95ebaffeab641907b38652f45c1502bd762972d/packages/ui/src/components/ai-elements/context.tsx#L61-L141)、[摘要和分项](https://github.com/zai-org/ZCode/blob/b95ebaffeab641907b38652f45c1502bd762972d/packages/ui/src/chat-input-toolbar/contextUsage.tsx#L962-L1075)、[浮层结尾](https://github.com/zai-org/ZCode/blob/b95ebaffeab641907b38652f45c1502bd762972d/packages/ui/src/chat-input-toolbar/contextUsage.tsx#L1076-L1103)、[压缩命令](https://github.com/zai-org/ZCode/blob/b95ebaffeab641907b38652f45c1502bd762972d/packages/ui/src/v4/SessionPane.tsx#L5218-L5235)。
