## 目标与验收

保持续想的核心：可预测、无信息依赖的工具与模型输出重叠执行；读取、验证、失败和授权处有明确反馈边界。桌面能完成从提交、排队、上下文选择、执行到检查变更和恢复的完整任务。

| 单元 | 文件边界与负责人 | 验收 | 回退 |
|---|---|---|---|
| 持久接收与队列 | service、Electron IPC；service agent | 相同ID不重复执行、丢ACK可查、保存失败不接收、重启暂停、取消保留后续 | 保留旧run兼容，基线源码可恢复 |
| 文件版本与变更 | executor、changes；core agent | SHA256写前检查、真实diff、外部修改拒绝覆盖/回退、意图先落盘 | 保留原内容，记录未知状态，不盲重放 |
| 文件上下文、模型协议与诊断 | workspace、provider、cli、diagnostics；主会话 | 附件快照及版本一致、路径限制、真实Flash流及原生工具后续轮 | 凭据只在本机系统加密位置；测试隔离目录 |
| 完整桌面流程 | renderer；renderer agent | 权威队列、文件预览/附件/diff/回退、连接诊断、最小窗口和键盘实测 | 老草稿/待发保留，禁止自动迁移执行 |
| 交付验收 | 主会话集成，独立交叉挑错 | 必要回归、真实模型任务、Electron与打包版实测 | 不替换旧产物，不发布正式release |

## 决定

- 采用DeepSeek官方当前模型名 `deepseek-flash`，显式支持思考开关。原生工具请求须保留服务商要求的reasoning字段；界面不展示内部推理正文。
- 密钥用Windows当前用户DPAPI保存于独立凭据目录，不进入仓库、报告或测试日志。
- 不引入ZCode完整Host/monorepo；借鉴权威输入接收、投影水位与读写前置条件。
- 本轮不安排Pro终审。完成局部功能与实物对抗验收后交付。
- 暂不声称操作系统沙箱、跨外部进程绝对CAS、多agent调度或MCP已实现。

## 已知边界与下一步

当前仍是单活动会话、未签名Windows便携包；未做长时负载或多平台发行。SHA检查不是跨外部进程原子CAS；文件自动回退有格式/大小限制；父进程退出且后台进程持有管道时有界退出并标记unknown，但不是Windows Job Object隔离。工具回执不自动证明任务验收文字的语义成立。

后续优先消息历史分页、可控数据保留、MCP真实工具接入、隔离多会话/多agent调度、签名与更新机制；详见[harness能力地图](harness-roadmap.md)。本轮不发布npm或正式Release，不安排Pro终审。
